## 2. 익숙한 상황에 빗대어 보기

주소 입력을 조립식 부품 상자 하나로 만든 설계입니다. 우편번호·도로명주소·상세주소를 한 상자에서 꺼내되, 연습용 주소 찾기와 실제 주소 검색기를 바꿔 끼우도록 구분합니다.

이 비유는 역할을 이해하기 위한 설명입니다. 실제 저장·승인·실행 조건은 코드 인수인계 보고서를 기준으로 확인합니다.

## 3. 서로 어떻게 연결되는가

카탈로그가 address-select-block 예제를 가리키고 내보내기 함수가 구성 파일을 묶습니다. 블록 안의 웹·모바일 어댑터와 외부 주소 검색 연결은 초안 계약이므로 등록·내보내기 성공과 구분합니다.

1. docs/sdui-address-select-block.md의 상태를 읽습니다. 성공 기준: draft와 동작 미검증 표시를 확인합니다.
