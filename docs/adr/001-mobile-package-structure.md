# ADR-001: 모바일 패키지 구조와 웹 자산 경계

- 상태: 승인 (2026-07-17, Gate 0 · 이슈 #123)
- 날짜: 2026-07-16 (승인 2026-07-17)
- 관련 이슈: #123

## 맥락

현재 Worker 패키지 `app/`은 Cloudflare 배포와 정적 웹 자산을 함께 관리한다. Capacitor 의존성과 네이티브 프로젝트를 같은 패키지에 넣으면 Worker 설치·배포가 무거워지고, 생성된 `www/`를 직접 수정할 위험이 생긴다.

## 결정

- Capacitor는 독립 패키지 `app/mobile/`에 둔다.
- `app/public/`을 웹 자산의 유일한 원본으로 유지한다.
- `scripts/sync-web-assets.mjs`가 `app/public/`을 `app/mobile/www/`로 완전 교체 복사한다.
- `www/`는 커밋하지 않는다. Android/iOS 네이티브 프로젝트는 소스 아티팩트로 커밋한다.
- 프로덕션 설정에 `server.url`을 사용하지 않는다.
- 네이티브 런타임에서는 서비스 워커 등록을 차단한다.

## 결과

웹과 앱이 같은 UI를 재사용하면서도 Worker와 네이티브 의존성 수명주기가 분리된다. 자산 동기화를 먼저 실행하지 않으면 네이티브 빌드가 오래된 UI를 포함할 수 있으므로 `cap:sync`가 동기화를 선행한다.

## 검증

- 동기화 테스트가 오래된 파일 제거와 중첩 자산 복사를 확인한다.
- `www/index.html`이 없으면 동기화가 실패한다.
- 네이티브 서비스 워커 차단 계약을 자동 테스트한다.
