# ADR-004: 모바일 녹음과 STT 경로

- 상태: 승인 (2026-07-17, Gate 0 · 이슈 #123)
- 날짜: 2026-07-16 (승인 2026-07-17)
- 관련 이슈: #123

## 맥락

웹/PWA의 Web Speech API 동작은 iOS WebView와 기기 상태에 따라 달라질 수 있다. 모바일 핵심 여정은 브라우저 음성 인식 지원 여부에 의존하면 안 된다.

## 결정

- 웹/PWA는 기존 Web Speech 경로를 유지한다.
- 모바일 v1은 foreground에서 오디오 파일을 녹음한 뒤 기존 STT 업로드 API로 전송한다.
- 마이크 권한 요청 전에 사용 목적을 표시한다.
- 플러그인은 Capacitor 8 지원, 최근 유지보수, 라이선스, Android/iOS 파일 형식과 인터럽트 처리를 spike로 검증한 뒤 선택한다.
- 전화, 앱 전환, 화면 잠금, 권한 거절, 업로드 실패의 상태 전이를 명시한다.
- 성공·취소·만료 시 임시 오디오를 삭제한다. 장시간 background 녹음은 v1 범위에서 제외한다.

## 결과

녹음 파일 저장 공간과 개인정보 노출 위험이 생기므로 최대 시간·크기와 정리 정책을 구현 전에 확정해야 한다. STT 전송 전 사용자의 명시적 중단·삭제 경로를 제공한다.
