# ADR-005: 모바일 로컬 데이터와 민감정보 저장

- 상태: 승인 (2026-07-17, Gate 0 · 이슈 #123)
- 날짜: 2026-07-16 (승인 2026-07-17)
- 관련 이슈: #123

## 맥락

앱 재시작과 네트워크 중단에도 작성 중 데이터가 보존되어야 하지만, 토큰·회의 원문·오디오를 같은 저장소에 두면 유출과 정리 실패 위험이 커진다.

## 결정

- 작은 비민감 설정과 초안 메타데이터는 Preferences 계열 저장소를 사용한다.
- 긴 전사 초안은 IndexedDB 또는 앱 전용 파일에 schema version과 함께 저장한다.
- 녹음 원본은 앱 전용 Filesystem에 저장하고 TTL·완료·취소 정리 규칙을 둔다.
- refresh token 같은 민감 자격증명은 OS secure storage만 사용한다.
- 분석 이벤트와 로그에는 토큰, 회의 원문, 파일명, 오디오 내용을 포함하지 않는다.
- 서버 동기화 요청은 idempotency key를 사용해 재연결 시 중복 생성을 막는다.

## 결과

저장 계층이 여러 개가 되므로 공통 repository/adapter와 마이그레이션 정책이 필요하다. 로그아웃·계정 삭제·기기 해제 시 서버 세션 폐기와 로컬 민감정보 삭제를 하나의 흐름으로 검증한다.
