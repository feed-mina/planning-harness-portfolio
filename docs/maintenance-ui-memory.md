# 유지보수 UI 메모

## 2026-07-13 — 일반 사무직 사용성

- 관련 이슈: [#106](https://github.com/feed-mina/planning-harness/issues/106)
- 기준: 마이페이지 유지보수 화면은 기술 용어와 긴 URL 노출을 최소화하고, 각 버튼이 하는 일과 결과를 한국어로 설명한다.
- 조직 초대: 생성 직후 초대 URL을 상태 메시지에 표시하지 않는다. 대기 중 초대는 목록의 `초대 열기`로 확인한다.
- 멤버 관리: 로그인한 사용자는 조직 멤버 목록에서 자신을 제거할 수 없다. UI와 API에서 모두 차단한다.
- 내보내기: 조직 사용량은 실제 `.xlsx` 파일로 생성하며, 헤더 서식·열 너비·첫 행 고정을 적용한다.
- 기기 등록: 등록 코드와 만료 시간만 보여 주고 전체 등록 URL은 상태 영역에 노출하지 않는다.
- 칸반: 카드에 `owner/repo`와 이슈 번호를 연결할 수 있다. 연결된 카드는 완료 시 GitHub 이슈를 닫고, 완료에서 다른 상태로 재개하면 다시 연다.

## 2026-07-13 — 일정·콘텐츠 유지보수

- 시간 설정: 빠른 시간 버튼과 중복되는 상대 시간 표시는 제거한다. 직접 지정은 체크/열기 뒤 저장했을 때만 `사용 중`으로 표시한다.
- 일정 목록: 저장한 시간 블록은 선택 날짜 일정에 유지하고 시간·메모·관리 열을 같은 행 기준으로 정렬한다.
- 콘텐츠: 작성은 AI를 사용하지 않으므로 AI 사용액 배지는 표시하지 않는다. 첨부는 명확한 `파일 선택` 버튼을 제공한다.
- 콘텐츠 목록의 본문 클릭은 읽기 전용 상세 모달을 열고, `편집` 버튼은 기존 수정 폼으로 이동한다.

## 2026-07-13 — 대시보드·회의록 설정

- 회의록 만들기의 현재 AI 설정 카드 전체는 마이페이지 설정으로 이동하는 링크로 사용한다.
- 대시보드 최근 회의록은 최신 3건만 표시하고, 전체 목록은 기존 `전체 보기`에서 확인한다.
