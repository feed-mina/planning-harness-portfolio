# NBlog SmartEditor 자동입력 — P0 실 네이버 검증 가이드

이 문서는 NBlog SmartEditor 자동입력 도우미(`app/nblog-smarteditor-client`)를
**실제 네이버 블로그 비공개 초안**에서 처음으로 검증하기 위한 단계별 체크리스트다.
실제 네이버 로그인이 필요해 사람이 직접 수행해야 한다(자동화 불가).

관련: 이슈 #193, #205(머지됨), 안정화 추적 이슈(아래 GitHub 이슈 생성 시 링크 추가).

## 0. 준비물

- [ ] 테스트용(또는 본인) 네이버 블로그 계정 — 실제 발행에 쓰지 않을 **비공개 초안**으로만 테스트
- [ ] Chrome 브라우저, 개발자 모드 사용 가능
- [ ] Planning Harness 계정 로그인 상태 (운영 또는 스테이징)
- [ ] `app/public/downloads/nblog-smarteditor-helper.zip` 또는 `app/nblog-smarteditor-client` 폴더 (압축해제된 확장 로드용)

## 1. 확장 설치

1. `chrome://extensions`를 연다.
2. **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다** → `app/nblog-smarteditor-client` 폴더 선택(또는 ZIP을 풀어서 그 폴더 선택).
4. 확장 아이콘이 툴바에 나타나는지 확인.

## 2. 연결 코드 발급

1. NBlog 발행 화면(`/nblog-automation/`)에서 확인 완료 상태인 글을 연다.
2. **자동입력 연결 코드 만들기** 클릭 → 확인 대화상자 승인.
3. **연결 코드 복사** 클릭 (10분 만료, 한 번만 표시됨에 유의).

## 3. 네이버에서 빈 초안 열기

1. 같은 Chrome에서 네이버에 로그인한다.
2. 연결 코드 발급 시 지정한 대상 블로그의 **글쓰기(SmartEditor)** 를 새로 연다.
3. 제목·본문이 완전히 비어 있는 상태인지 확인한다(자동 저장된 임시글이 남아있지 않은지).

## 4. 자동입력 실행 + 검증 항목

확장 아이콘 팝업에 연결 코드를 붙여넣고 연결한다. 아래 항목을 **모두** 확인한다.

- [ ] **입력 직후 보임**: 팝업이 "입력 완료"로 바뀐 직후 SmartEditor 화면에 제목·본문·(있다면)태그가 실제로 렌더링되어 보인다(팝업만 성공을 주장하고 화면은 비어 있는 케이스가 없는지).
- [ ] **임시저장 정상 동작**: 네이버의 자동 임시저장 또는 수동 "임시저장" 버튼이 입력된 내용을 포함해 정상 동작한다(저장 중 오류가 없는지).
- [ ] **재열람 시 유지**: 다른 탭으로 갔다가 돌아오거나, 목록에서 임시글을 다시 열었을 때 입력된 제목·본문·태그가 그대로 남아 있다(브라우저 표시상으로만 있고 네이버 내부 상태에는 반영 안 된 "유령 텍스트"가 아닌지 확인하는 핵심 항목).
- [ ] **줄바꿈 보존**: 여러 줄로 된 본문에서 줄바꿈이 원래 초안과 동일하게 유지된다(한 줄로 뭉개지거나 빈 줄이 사라지지 않는지).
- [ ] **한글 정상 표시**: 한글이 깨지거나 자모가 분리되지 않고 정상 렌더링된다(인코딩·IME 관련 문제 확인).
- [ ] **중복 없음**: 제목·본문·태그가 각각 정확히 한 번만 들어가 있다(execCommand 폴백 경로에서 중복 삽입되지 않는지, 같은 연결로 재시도했을 때 내용이 두 번 붙지 않는지).
- [ ] **수동 경계 유지**: 로그인·CAPTCHA·사진·영상·장소·미리보기·발행 중 어느 것도 자동으로 눌리지 않았다.

## 5. 실패 케이스도 최소 1회 확인 (선택, 가능하면 수행)

- [ ] 이미 내용이 있는 글에서 연결 → `editor_not_empty`로 안전하게 중단되는지
- [ ] 다른 블로그의 글쓰기 화면에서 연결 → `target_blog_mismatch`로 중단되는지
- [ ] (가능하다면) 네트워크를 잠깐 끊거나 탭을 빠르게 전환해 입력 도중 실패를 유도 → 이어하기(P1-b) 동작 확인은 이 작업이 배포된 뒤에 재검증

## 6. DOM 스냅샷 캡처 (P1-a 준비용 — 중요)

이후 단계(P1-a, 실 DOM fixture 계약 테스트)에서 지금의 fake DOM 대신 **진짜 네이버 SmartEditor HTML 구조**를 테스트 fixture로 쓸 예정이다. 검증 중 아래를 함께 캡처해 남겨 달라.

1. 자동입력 성공 직후, 크롬 개발자 도구(F12) → Elements 탭에서 `.se-main-container`(본문 영역)를 감싸는 상위 컨테이너를 찾는다.
2. 우클릭 → **Copy → Copy outerHTML**.
3. 개인정보(실제 초안 문구·계정명 등)를 일반 텍스트로 치환한 뒤, 별도 파일로 저장해 공유(예: `docs/fixtures/naver-smarteditor-dom-snapshot.html` — 저장 방식은 별도 상의).

## 7. 결과 기록

검증 완료 후 아래 형식으로 추적 이슈에 코멘트를 남긴다.

```markdown
## P0 검증 결과 (YYYY-MM-DD)

- 브라우저/OS: 
- 확장 버전: manifest.json version
- 4번 항목 결과: [ ] 모두 통과 / 실패 항목: ...
- 5번 항목 결과: ...
- DOM 스냅샷: 첨부 여부
- 기타 이상 현상:
```

결과가 "모두 통과"면 P1-a(실 DOM fixture 계약 테스트) 착수를 요청한다.
실패 항목이 있으면 어떤 검증 항목에서 무엇이 어긋났는지가 다음 작업(P1-a/P1-c)의 입력값이 되므로 최대한 구체적으로 남긴다.
