주식 관리 GUI 설치

dad-stock-bot 저장소를 내려받아 아빠_주식_확인판.bat 을 실행하면 주식 현황 GUI가 열립니다. 아래 순서대로 준비하세요.

1. 저장소 내려받기

GitHub 저장소를 클론하거나 ZIP 으로 내려받습니다.

git clone https://github.com/feed-mina/dad-stock-bot.git
GitHub 저장소 열기 ZIP 다운로드

2. 실행하기

내려받은 폴더에서 배치 파일을 더블클릭하거나, 명령창에서 아래 경로를 실행합니다.

D:\dad-stock-bot\dad-stock-bot\아빠_주식_확인판.bat

경로는 저장소를 내려받은 위치에 맞춰 바꿔 주세요. 실행 시 Windows SmartScreen 경고가 뜨면 “추가 정보 → 실행”을 선택합니다.

3. 준비물

  • Windows 10/11 (배치 파일 실행 환경)
  • 저장소 README 에 명시된 실행 의존성(예: Python 등)
