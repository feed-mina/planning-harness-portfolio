ASK/Todo Hub

여러 로컬 Git 프로젝트의 ASK/Todo 기록, 실행 시각, 즉시 캡처를 한곳에서 관리하는 Windows 제어 센터입니다.

어떤 도구인가요?
  • 여러 Git 프로젝트를 한 번에 찾아 등록하거나 GitHub URL에서 clone합니다.
  • 프로젝트별로 하루 여러 실행 시각을 설정하고 Windows 예약 작업을 관리합니다.
  • 현재 Git 이력과 작업 트리에 근거해 ASK/Todo 기록을 준비합니다.
  • 개인 PC 모드와 영구 설정을 남기지 않는 임시 PC 모드를 구분합니다.
  • GitHub 비밀번호나 PAT를 저장하지 않으며 사용자 확인 없이 push하지 않습니다.
개인 PC용 Installer

시작 메뉴와 제거 프로그램에 등록되는 권장 설치 방식입니다. 제거 시 ASK/Todo 설정과 로그는 기본적으로 보존합니다.

📥 ASKTodoHub-Setup-latest.exe
임시 PC용 Portable

ZIP을 원하는 폴더에 풀어 실행합니다. 임시 PC 모드에서는 영구 예약 작업을 만들지 않고 Hub 소유 리소스만 정리합니다.

📦 ASKTodoHub-portable.zip
버전과 무결성 확인

공개 버전 정보에서 최신 버전과 파일 크기를 확인하고 SHA-256 파일의 값과 다운로드한 파일을 비교하세요.

SHA256SUMS.txt 버전 정보 사용방법 PDF
개인 PC
  1. Installer를 실행하고 Git, PowerShell 상태를 확인합니다.
  2. 여러 로컬 폴더 또는 GitHub URL로 프로젝트를 추가합니다.
  3. Claude/Codex와 09:00, 13:00, 17:30 같은 실행 시각을 지정합니다.
  4. 등록 결과와 예약 작업 상태를 확인합니다.
PC방·공용 PC
  1. Portable ZIP을 풀고 임시 PC 모드를 선택합니다.
  2. 즉시 캡처를 사용하며 영구 예약 작업은 만들지 않습니다.
  3. 종료 전에 임시 정리의 dry-run 목록을 확인합니다.
  4. Git credential과 브라우저 로그인은 시스템 안내에 따라 별도로 로그아웃합니다.
문제 해결
  • SmartScreen: 이 페이지의 파일명과 SHA-256을 확인한 뒤 실행 여부를 결정하세요.
  • Git 없음: Windows용 Git을 설치하고 새 터미널에서 다시 실행하세요.
  • 권한 없음: Hub는 관리자 권한을 기본 요구하지 않습니다. 예약 작업이 차단되면 즉시 캡처를 사용하세요.
  • 기존 폴더: clone 대상 폴더를 덮어쓰지 않습니다. 다른 위치를 선택하거나 기존 clone을 등록하세요.
  • 사내망: 이 운영 도메인의 다운로드 경로와 github.com clone 접근이 허용되는지 확인하세요.

다운로드 파일과 체크섬은 같은 배포에서 함께 게시됩니다. 단일 EXE만 복사하는 기존 방식 대신 installer 또는 portable ZIP 전체를 사용하세요.
