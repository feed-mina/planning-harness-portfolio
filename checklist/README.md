# 업무 실천 체크리스트

대표 업무 피드백을 하루 흐름 순서의 실천 체크리스트로 만든 개인 도구.

핵심 원칙: **범위는 좁게, AI 답은 검증하고, 오늘 판단 가능한 작은 결과물을 빨리 만들어 직접 확인 후 짧게 보고한다.**

## 어디서 쓸 수 있나

| 위치 | 용도 |
|---|---|
| **사이트** `/ai-harness/` | 앱 사이드바 → 기획 하네스 루프 → 업무 실천 체크리스트 |
| `업무-실천-체크리스트.html` | 오프라인용 단독 파일 (더블클릭으로 열기, 서버 불필요) |
| `업무-실천-체크리스트.md` | 같은 내용의 마크다운 버전 (Obsidian·인쇄·검색용) |

항목의 단일 소스는 `checklist-items.json`이고, 위 세 곳은 여기서 생성된다 (아래 "항목을 고칠 때" 참고).

사이트 버전과 단독 HTML은 기능이 같지만 두 가지가 다르다.

- 사이트 버전에는 **"지키되, 받아들이지 않을 것" 섹션이 없다.** URL을 아는 사람은 누구나 접근할 수 있어 개인적인 내용은 싣지 않았다. 그 섹션은 이 폴더의 HTML·마크다운에만 있다.
- 체크 상태는 **브라우저·위치별로 따로 저장**된다. 사이트에서 체크한 기록과 단독 HTML에서 체크한 기록은 공유되지 않는다.

## 사용법

1. `업무-실천-체크리스트.html`을 브라우저에서 연다 (더블클릭이면 충분, 서버 불필요)
2. 하루 흐름 8개 섹션을 순서대로 펼쳐 체크: 🌅시작 → 📥업무수신 → 🤖AI사용 → 🔍5층분리 → ✅검증 → ❓질문 → 📋보고 → 🌙마무리
3. 질문/보고 섹션의 템플릿은 "복사" 버튼으로 바로 복사
4. 하단 "새 하루 시작" 버튼: 체크 전체 초기화 + 시작 날짜 기록
5. "지난 기록" 섹션(📅): 날짜별 진행률이 자동으로 쌓인다
   - 체크할 때마다 그날의 `완료/전체 · %`가 저장되고, 날짜·요일·진행바로 표시
   - "새 하루 시작"을 눌러도 이전 날짜 기록은 지워지지 않음 (같은 날짜엔 최대 진행률 유지)
   - 최근 120일 보관
6. 하단 "편집" 버튼: 항목을 내 상황에 맞게 고칠 수 있다
   - 항목 문구를 눌러 수정, ✕ 버튼으로 삭제, 그룹마다 "＋ 항목 추가"
   - "기본 항목 복원": 지우거나 문구를 고친 기본 항목을 원래대로 되돌림 (직접 추가한 항목은 유지)
   - 편집 내용은 저장되어 새로고침·"새 하루 시작" 후에도 유지되고, 기존 체크 기록도 밀리지 않음

체크 상태는 브라우저 `localStorage`에 저장되므로 새로고침해도 유지된다.
(claude.ai 아티팩트 환경에서는 전용 `window.storage` API를 자동으로 사용한다 — 두 환경 모두 동작)

"지키되, 받아들이지 않을 것" 섹션은 체크 항목이 아닌 경계선 리마인더다.

## 항목을 고칠 때

앱에서 "편집" 버튼으로 고치는 건 **그 브라우저에만** 적용된다. 기본 항목 자체를 바꾸려면:

1. **`checklist/checklist-items.json` 하나만 고친다** (단일 소스)
2. `cd app && npm run build:checklist` 실행

그러면 아래 세 산출물이 함께 갱신된다.

| 산출물 | 갱신 범위 |
|---|---|
| `app/public/assets/practice-checklist.js` | `<checklist:sections>` 마커 사이 |
| `checklist/업무-실천-체크리스트.html` | `<checklist:sections>` 마커 사이 |
| `checklist/업무-실천-체크리스트.md` | 파일 전체 |

산출물을 직접 고치면 다음 생성 때 덮어써진다. 마커도 지우면 안 된다 (생성 위치를 못 찾아 실패한다).

**어긋나면 CI가 잡는다.** `npm test`에 `check:checklist`가 포함돼 있어, 산출물이 단일 소스와 다르면 실패하고 `npm run build:checklist`를 실행하라고 알려준다.
