# /split-requirements

## 목적
큰 기능이나 요청을 세부 요구사항으로 분해해 구현 가능한 단위로 만듭니다.

## 입력
- 기능명 또는 요구사항 설명

## 출력
- `requirements.md`

## 처리 규칙
1. 기능을 핵심 작업 단위로 나눕니다.
2. 필수/선택 우선순위를 표시합니다.
3. 의존 관계를 명확히 합니다.
4. 구현 전 확인이 필요한 항목은 별도 표시합니다.

## 출력 형식
```markdown
## 요구사항 분해: [기능명]

### Phase 1 (필수)
- [ ] 항목 1
- [ ] 항목 2

### Phase 2 (선택)
- [ ] 항목 3

### 의존성
- Phase 1 완료 후 Phase 2 진행
```
