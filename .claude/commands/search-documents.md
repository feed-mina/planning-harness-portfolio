# /search-documents

## 목적
기획 루프에 필요한 기존 문서, 회의록, 이슈, 지식베이스를 한 번에 찾아 정리합니다.

## 입력
- 조사할 주제나 기능명

## 출력
- `docs-found.md` 형식의 근거 목록

## 처리 규칙
1. 저장소의 기존 문서와 스펙을 먼저 검색합니다.
2. 회의록, 이슈, 관련 코드 또는 문서를 함께 확인합니다.
3. 중복을 제거하고, 핵심 근거를 요약합니다.
4. 불확실한 내용은 확인이 필요하다고 표시합니다.

## 출력 형식
```markdown
## 검색 결과: [주제]

### 기존 문서
- [문서명] - [핵심 요약]

### 관련 이슈
- #[번호] - [요약]

### 추가 확인 필요
- [불확실한 항목]
```
